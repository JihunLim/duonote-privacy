## 앱 정보

- **앱 이름**: DuoNote: 손글씨 다이어리 (DuoNote: Handwriting Diary)
- **플랫폼**: iOS 27.1 이상 (iPhone)
- **개발자**: Jihun Lim

## 주요 기능
- iPhone Duo 펼침면: 펼치면 두 쪽이 가죽 다이어리처럼 열리고, 접힌 바깥 화면은 겉표지
- 일반 iPhone 에서는 한 쪽씩 화면 가득 (가로 두 쪽 펼침 선택)
- 펜·형광펜·지우개·올가미, Apple Pencil 지원
- 스티커, 사진, 카메라, 문서 스캔, PDF 가져오기
- 카테고리별 인덱스 탭과 속지, 먼슬리 달력, 빠른 메모
- 로그인 없이 기기에서 사용, Apple 로그인 시 종단간 암호화 백업·동기화
- AI 요약·전사·번역·질문 (Anthropic Claude, 동의 후 버튼을 누를 때만)
